# Detalles del proyecto

## ¿Qué es Markdown?

Markdown es un lenguaje de marcado que permite crear documentos con títulos, listas, enlaces, imágenes y tablas.

## ¿Para qué sirve GitHub?

GitHub permite almacenar proyectos, compartir código y colaborar con otras personas.

## Rutas relativas

Una ruta relativa permite acceder a un archivo dentro del repositorio.

Ejemplo de imagen local:

`assets/mi-imagen.png`

Ejemplo de enlace al documento principal:

`../markdown.md`

## Conclusión

Markdown y GitHub son herramientas útiles para crear y publicar documentación técnica.
