# La tecnología en la educación

## Importancia de la tecnología en el instituto

La tecnología facilita el aprendizaje y mejora la comunicación. Las herramientas digitales son **muy útiles**, permiten aprender de forma *interactiva* y ayudan a trabajar con código como `print("Hola mundo")`.

## Ejemplo de código

```python
nombre = "Estudiante"
print("Bienvenido al instituto", nombre)
```

## Ventajas de la tecnología

- Facilita el acceso a la información.
- Mejora el trabajo en equipo.
- Permite aprender desde cualquier lugar.

## Pasos para realizar un trabajo

1. Buscar información.
2. Organizar las ideas.
3. Escribir el documento.
4. Revisar el resultado.
